# Prospect → Turnkey Smart-DID Build (corporate SOP)

The repeatable way we turn any prospect into a ready-to-pitch, ready-to-publish
Telvergence package. Runs the same every time so quality is a floor, not a hope.

## Inputs (gather first)
- **[URL]** prospect's existing website (required — it's the benchmark to beat)
- **[NAME] / [CITY] / [STATE + LICENSE #]** (license of record if the vertical is regulated)
- **[VERTICAL]** (electrical, roofing, public-adjusting, wellness, etc.)
- Line count intent: **10+ lines** → full email sequence + campaign build; **<10** → verbal-TPV hybrid.

## Step 1 — Benchmark the existing site (the axis David wants beaten)
Fetch [URL]. Capture verbatim taglines/headlines and record:
phone numbers + click-to-call?, tracking present?, lead-form fields (esp. missing
email/SMS), CTAs, services, trust signals (license/insured/reviews/financing/years),
24-7 answer / chat, mobile & speed feel, GBP/directory NAP consistency.
Score on 6 axes: **phone/lead-capture · speed/mobile · trust · offer clarity · SEO/NAP · follow-up.**
Name the single biggest gap — usually **"what happens after interest"** (untracked
number, no follow-up, no outbound).

## Step 2 — Design the offspring (turnkey Smart-DID site)
Clone the house template (see Assets). Every prospect page includes, in order:
1. Hero: the one-line concept ("10 numbers. One brain." for a 10-line pack).
2. **Live benchmark** — their real site's gaps vs. the offspring's wins (use Step 1 findings).
3. **10-line Smart-DID grid** — each DID a *sensor + router*, tailored to the vertical.
   Always include a market-fit line (e.g. **Spanish line** in bilingual metros) and
   channel-attribution DIDs (Google / truck-wrap / direct-mail) + an outbound branded CID.
4. **The brain** — DID → source-tag → language route → priority → 24/7 AI answer →
   book/SMS/auto-callback → one command center. State the moat: we control dial tone
   (Vitelity API → our network) → **zero lead-data leakage.**
5. Telemarketing-centric core (outbound dialer + inbound tracked + command center).
6. Video block (embed the :90 walkthrough).
7. 10-line pack offer + economics + engagement tiers.

## Step 3 — :90 video script
Split-screen "their site vs. the offspring." Beats: hook (their site) → problem
(money + language walking out) → reveal (the grid) → the brain + core → risk reversal
(10-line pack, $0 out of pocket first) → CTA. Include shot list + on-screen supers.

## Step 4 — Vanity / DID scheme
Vertical-specific vanity ideas + a **distinct tracked DID per source.**
⚠️ Vanity spellings are ILLUSTRATIVE — **pull real DIDs from the wholesale portal
before launch; never publish an unowned number.**

## Step 5 — Offering
Attach the standard onboarding guarantee/indemnification (counsel-review each send;
John Campbell removed — counsel routing neutral). $22.95/line advanced before charge;
100% satisfaction/full refund; no contract; no SSN/credit.

## Guardrails (non-negotiable)
- Compliance on every page/script: **TCPA, Do-Not-Call scrubbed, state LICENSE # shown.**
- Substantiate or soften hard claims (E911, "carrier-grade") before external use.
- Legal template stays **counsel-review-gated.**
- **Nothing filed to Drive or sent via Gmail without David's approval.**
- **Sites stay up** — never flip repos private before the Cloudflare Pages path is wired
  (private repo on free GitHub Pages = whole site goes dark).
- Vanity/DID: never publish a number we don't own.

## Handoff back to the main session (final synthesis)
The cowork/research session returns: (a) the benchmark scorecard, (b) filled field
values [NAME]/[CITY]/[LICENSE]/[VERTICAL]/vanity ideas, (c) any gathered assets/notes.
The **main Claude Code session** then: builds/finalizes the turnkey HTML in the house
style, publishes it to `main` at the vault path, links it into the showroom + master
catalog, and **curl-verifies 200.** Real DIDs swapped in before the number goes public.

## Definition of done
Turnkey site + :90 script + DID scheme + offer delivered; published & 200-verified
(once Pages is live); linked in showroom/catalog; illustrative numbers flagged for
real-DID swap; compliance + counsel gates intact.
