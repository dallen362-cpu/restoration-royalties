The engine how

Every card above is generated from brand-kit/ — one template (build.py), one shared stylesheet (brand.css), and one JSON data file per brand. A new industry model is a data file plus one command. That is the Mashup Studio: change the content, credentials, accent, and layout per brand without ever hand-forking HTML.
